# Resume Buddy

A web application for building resumes and analyzing PDF resumes to help users improve their job applications.

## Features

* Upload and analyze PDF resumes.
* Analyze resumes based on a target job role and job description.
* Get feedback to improve your resume.
* Simple and user-friendly interface.

## Tech Stack

* Frontend: HTML, CSS, JavaScript / React
* Backend: Node.js, Express.js
* PDF Processing: pdf-parse
* Database: SQLite

## Getting Started

1. Clone this repository.
2. Install the required dependencies.
3. Configure your environment variables.
4. Start the backend and frontend servers.

Refer to the project configuration files for the required commands and settings.
